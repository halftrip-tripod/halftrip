# Play Console 설문 답안지 (2026-08-12 규희 작성)

> 목적: 비공개 테스트 트랙 올리기 전 콘솔이 요구하는 **필수 설문 4종**을 미리 확정.
> ⚠️ 답안은 **개인정보처리방침**(`web/privacy.html` = `info_screens.dart` 원문)과 100% 일치해야 심사 리스크 없음. 방침 바뀌면 이 문서도 같이 고칠 것.
> 근거: 방침 §2 수집항목, §4 제3자 제공 안 함, §5 위탁(OpenAI·Google·Render·카카오/네이버), §8 HTTPS 암호화.

## 1. 데이터 보안 (Data safety) — 제일 중요

### 1-1. 개요 토글
| 질문 | 답 | 근거 |
| --- | --- | --- |
| 앱이 사용자 데이터를 수집·공유하나요? | **예(수집함)** | 방침 §2 |
| 전송 중 데이터를 암호화하나요? | **예** | 방침 §8 HTTPS |
| 사용자가 데이터 삭제를 요청할 수 있나요? | **예** | 앱 내 회원탈퇴 + 이메일(방침 §7) |
| 데이터를 제3자와 **공유(share)** 하나요? | **아니요** | 방침 §4 "제3자 제공 안 함". OpenAI·Google·Render는 **위탁(처리자)** — Google 정의상 "공유"에 해당 안 됨 |
| Families(아동) 정책 대상인가요? | **아니요** | 만 14세 미만 수집 안 함, 타깃 성인 |

> 💡 **"공유 아니요"가 핵심.** 위탁사(OpenAI/구글/Render)는 우리 지시로만 처리하는 service provider라 Play 기준 "sharing"이 아니라 "collection". 헷갈려서 "공유 예"로 찍으면 안 됨.

### 1-2. 수집하는 데이터 유형 (각 항목: 수집=예 / 공유=아니요 / 목적 / 필수여부 / 암호화=예)

| Play 데이터 유형 | 우리 항목 | 목적 | 필수/선택 |
| --- | --- | --- | --- |
| **개인정보 > 이름** | 성명 (정산 신청 시) | 앱 기능(정산 지원) | 선택(정산 쓸 때만) |
| **개인정보 > 이메일 주소** | 소셜 로그인 이메일 | 계정 관리 | 필수 |
| **개인정보 > 전화번호** | 전화번호 (정산 신청 시) | 앱 기능(정산 지원) | 선택 |
| **개인정보 > 사용자 ID** | 카카오·네이버 회원번호, 닉네임 | 계정 관리 | 필수 |
| **개인정보 > 기타(주소)** | 거주지(시·군·구) | 앱 기능(지역 자격 안내) | 선택 |
| **위치 > 정확한 위치** | 인증사진 EXIF의 GPS | 앱 기능(방문 검증) | 선택(인증샷 올릴 때만) |
| **사진 및 동영상 > 사진** | 인증샷·영수증·숙박확인서 이미지 | 앱 기능(환급 증빙) | 선택 |
| **앱 활동 > 앱 상호작용** | 알림 설정, 좋아요·저장 기록 | 앱 기능 | 선택 |
| **앱 활동 > 기타 사용자 생성 콘텐츠** | 커뮤니티 게시글·댓글 | 앱 기능(커뮤니티) | 선택 |
| **기기 또는 기타 ID** | FCM 푸시 토큰 | 앱 기능(알림 전송) | 선택 |

- 위 **전 항목 공통**: 전송 중 암호화=예, 제3자 공유=아니요, 사용자가 삭제 요청 가능=예.
- **정확한 위치**: "실시간 위치 추적 아님, 사용자가 올린 사진에 든 촬영 위치만" — 심사 메모에 적어두면 좋음.
- 접속 로그(방침 §2-⑤, 3개월): 내부 운영 로그로 데이터 보안 신고 대상 아님(선택). 굳이 넣는다면 "앱 활동 > 기타".

## 2. 콘텐츠 등급 (IARC 설문)

| 문항 | 답 |
| --- | --- |
| 폭력 | 없음 |
| 성적 콘텐츠 | 없음 |
| 욕설/비속어 | 없음 |
| 마약·음주·흡연 묘사 | 없음 |
| 도박(모의 포함) | 없음 |
| 공포 | 없음 |
| **사용자 간 상호작용/소통 기능** | **예** (커뮤니티 글·댓글) |
| 사용자 생성 콘텐츠 공유 | **예** (커뮤니티) |
| 사용자 위치를 다른 사용자와 공유 | **아니요** |
| 디지털 구매(앱 내 결제) | **아니요** (온라인몰은 외부 사이트 링크) |

> 예상 등급: **전체이용가(만 3세+)** + "사용자 상호작용" 표시. 최종 등급은 IARC가 자동 산정.
> ⚠️ 커뮤니티가 있으므로 "사용자 상호작용=예"는 반드시 정확히 — 나중에 발각되면 앱 정지 사유.
