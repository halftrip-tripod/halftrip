## 1. 전체 진행률

**화면(UI)은 전 탭 100% 완성** (목업 1:1 리스킨 완료). 남은 것은 데이터 연결·백엔드 보강·출시 준비.

| 영역 | 진행률 | 남은 것 |
| --- | --- | --- |
| 내여행 (여행 등록~상세 4단계) | ██████████ 95% | 게이지 보강 필드 연결 |
| 인증·기록 (인증샷·OCR·숙박·증빙) | █████████░ 90% | 위치 검증 표시 |
| 정산 | ██████████ 95% | 마감 D-day 표시 |
| 지도 (구글맵) | ██████████ 100% | — |
| 알림 | ████████░░ 85% | 딥링크 데이터 연결 |
| 계정·로그인 | ███████░░░ 70% | **소셜 실 OAuth** |
| 코스 (만들기 3방식·코스함) | █████░░░░░ 50% | 직접 만들기·AI·코스함 서버화 |
| 커뮤니티 | ████░░░░░░ 40% | 서버 연동 (현재 기기 저장으로 동작) |
| 홈·온라인몰·지역상세 | ███░░░░░░░ 30% | 실데이터 연결 |
| 출시 준비 (서명·스토어) | █░░░░░░░░░ 10% | 8월 진행 |

**종합: 약 70%** — 핵심 사용자 여정(가입→여행 등록→인증·기록→정산 신청)은 실서버 E2E 통과 상태.

## 2. ✅ 완료된 부분

- **핵심 여정 전체**: 로컬 로그인·거주지 → 여행 추가→상세 4단계 → 인증샷 AI 판정(촬영시각 검증) → 영수증 OCR → 숙박확인서·PDF → 증빙 패키지 → 정산 신청(실명·전화 수집)
- **지도**: 구글맵 전환 — 방문 순서 번호 핀 + 탭 정보창 + 브랜드 스타일 (웹·앱 공용)
- **코스(유튜브)**: 링크 입력 → 서버 잡 생성 → 진행 UI → 완료 시 확정 코스 연결 + 장소 구글 정규화
- **가맹점**: 구글 플레이스 보강 API (전화·주소·길찾기 링크) — 서버 완료, 화면 연결만 남음
- **알림**: 목록·모두읽음·설정 2토글·관심지역
- **커뮤니티(1단계)**: 글쓰기·좋아요·저장 기기 영속 + 지난여행 후기 루프(작성·나만보기·공개 전환)

## 3. 🔲 남은 부분 (영역별)

- **소셜 로그인 실 OAuth** — 카카오·네이버 (클라+서버 모두, 검수 리드타임 有 → 최우선)
- **코스 완성** — 직접 만들기(장소검색·저장), AI 추천, 코스함 서버 저장
- **홈·온라인몰·지역상세 실데이터** — API는 대부분 준비됨
- **백엔드 보강 16건** — 딥링크 refType·위치검증 배선·체크리스트·거주지/프로필 등 ([목록](backend-api-requests.md))
- **커뮤니티 서버(J)** — ⚠️ **담당 미정 항목** — 테이블·API 신설 (명세는 backend-handoff J항에 완비). 8/4 착수 필요 → **목요일 회의에서 담당 확정** (규모: 백엔드 2~4일 + 클라 스왑 2~3일(규희))
- **에셋** — 지역·관광지 AI 일러스트 (지역 16곳은 선제작 가능)
- **출시** — Android 서명·스토어 등록·비공개 트랙 (W9~10)
