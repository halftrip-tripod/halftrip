# 지역 마그넷 프롬프트 25종 (2026-09-01)

> 규희·AI 로컬 참고용. 홈 지도의 "다녀온 지역" 도장(현재 노란 별)과 지역 일러스트를
> **하나의 마그넷 자산으로 통일**하기 위한 생성 프롬프트.
> 기존 `assets/magnet/gochang.png`(고인돌)·`wando.png`(전복) 톤을 기준으로 잡았다.

## 스타일 기준 — 기존 2종에서 뽑은 규칙

| 요소 | 규칙 |
| --- | --- |
| 형태 | 오브젝트 **하나만**, 정중앙, 정면~살짝 위에서 본 각도 |
| 볼륨 | 통통하게 부푼 풍선 느낌. 각진 모서리 없이 전부 둥글게 |
| 표면 | 매끈한 그라데이션 + 위쪽에 부드러운 하이라이트 |
| 배경 | **투명 배경**. 지도 핀으로 올릴 자산이라 흰 배경이면 네모가 그대로 보인다 |
| 금지 | 글자, 로고, 사람, 배경 풍경, 테두리 프레임, 바닥 그림자 |
| 비율 | 정사각 1:1, 고해상도 |

### 받침(잔디)은 소재에 맞춰서

고인돌처럼 **땅에 놓이는 소재**는 잔디 받침이 자연스럽고, 전복·굴비처럼 그렇지 않은
소재는 오브젝트만 둔다. 기존 2종이 이 기준대로 되어 있으니 그대로 간다.

받침이 어울리는 소재: 고인돌 · 영남루 · 천문대 · 땅끝탑 · 월출산 · 다랭이논 · 한반도지형

## 공통 프롬프트 (실제 사용한 것)

`[내용]` 자리에 아래 각 지역의 소재만 갈아 끼운다.

```
A cute glossy 3D balloon-style fridge magnet illustration of [내용]
inflated puffy rounded shapes like a mylar balloon, soft plastic sheen
with gentle highlights, thick white sticker border, natural colors true
to the real object with slightly candy-toned saturation, centered single
object, transparent background, clean vector-like edges, mobile app icon
aesthetic, no text, square 1:1 aspect ratio, composition fitted within
a square canvas
```

`thick white sticker border`가 들어 있어서 결과물에 흰 테두리가 생긴다.
25종 전부 이 프롬프트로 만들어서 톤이 맞다.

## 소재 설명 — 위 프롬프트의 `[내용]` 자리에 들어간 것

아래는 각 지역에 무엇을 그렸는지 적은 것이다. 실제 생성은 위 영문 프롬프트의
`[내용]`을 이 소재로 바꿔서 했다.

### 1. 강진 — 고려청자
```
연한 비취색 고려청자 매병 하나, 어깨가 둥글고 아래로 갸름하게 좁아지는 형태,
표면에 흰 학과 구름 상감 무늬
```

### 2. 거창 — 사과
```
빨갛게 잘 익은 사과 한 알, 짧은 갈색 꼭지와 초록 잎 두 장, 볼이 통통한 형태
```

### 3. 고성 — 공룡
```
귀여운 초식 공룡 한 마리, 긴 목과 통통한 몸통, 연두색 피부에 등을 따라 작고 둥근 돌기,
순한 표정
```

### 4. 고창 — 고인돌 *(재생성 시)*
```
넓적한 덮개돌 하나가 굵은 받침돌 두 개 위에 얹힌 고인돌, 회색 화강암에 둥글둥글한 표면
```

### 5. 고흥 — 우주 로켓
```
하늘로 솟는 하얀 우주 로켓 하나, 빨간 원뿔 머리와 파란 삼각 꼬리 날개,
아래쪽에 작고 동그란 주황 화염
```

### 6. 남해 — 다랭이논
```
바다를 향해 계단처럼 내려가는 초록 계단식 논 한 조각, 층마다 부드러운 곡선,
```

### 7. 밀양 — 영남루

### 8. 산청 — 한방 약탕기

```
둥근 옹기 약탕기 하나, 짙은 갈색 몸통과 옆으로 뻗은 손잡이, 뚜껑 틈으로 모락모락 김
```

### 9. 영광 — 굴비

### 10. 영암 — 월출산

### 11. 영월 — 한반도지형

### 12. 영천 — 천문대와 별

```
활짝 핀 빨간 튤립 한 송이, 곧은 초록 줄기와 길쭉한 잎 두 장
```

## 소재를 고른 기준

- **그 지역 하면 바로 떠오르는 것 하나**만. 두 개 이상 섞으면 작은 크기에서 뭉갠다
- **다른 지역과 안 겹치게.** 한방 소재가 셋(산청·함양·제천) 겹칠 뻔해서
  산청=약탕기 / 함양=산삼 / 제천=청풍호 배로 갈랐다
- **작게 줄여도 실루엣이 읽히는 것.** 지도 핀은 30~40px로 들어간다.
  다랭이논·월출산처럼 풍경인 소재는 윤곽이 단순한 각도로 지정했다

## 넣는 방법

1. 25장을 `assets/magnet/{파일명}.png`로 저장 (누끼 딴 투명 PNG 권장)
2. `home_tab.dart`의 `_magnetAssets` 맵에 25개 항목 등록
3. `_RegionPinDot`의 visited 분기를 노란 별 → 마그넷 이미지로 교체
4. 지역 상세 일러스트도 같은 자산을 크게 써서 톤을 맞춘다

투명 배경으로 안 나오는 도구를 쓴다면 흰 배경으로 뽑고 누끼를 따야 한다.
이때 **잔디 받침이 있는 소재는 받침까지 오브젝트로 남겨야** 한다 — 받침만 잘리면
고인돌이 공중에 뜬다.
