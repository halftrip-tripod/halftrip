## 3. 스크린샷 8장 구성안 (순서 = 어필 순서)

각 장 = 상단 헤드라인 카피(큰 글씨) + 프레임 안 실앱 캡처. 배경은 하늘색 그라데이션 톤 통일.

| # | 헤드라인 | 서브카피 | 캡처 화면 |
| --- | --- | --- | --- |
| 1 | **복잡한 반값여행, 하프트립 하나로** | 정보 확인부터 인증·증빙·정산 관리까지 | 홈 (전국지도 — 메인 슬라이드) |
| 2 | **신청 정보 확인하고 바로 신청까지** | 지역별 조건·일정 보고 신청 사이트로 이동 | 지역 상세 (신청 일정·환급 조건) |
| 3 | **뭘 해야 할지 다 알려드려요** | 여행 등록하면 체크리스트 자동 생성 | 내 여행 상세 (단계+체크리스트) |
| 4 | **사진만 찍으면 방문 인증 끝** | 촬영 시간·위치를 자동 검증 | 인증샷 업로드 (검증 완료 뱃지) |
| 5 | **영수증·서류는 알아서 정리** | 금액 자동 입력, 증빙 PDF 자동 완성 | 영수증 OCR 결과 |
| 6 | **유튜브 영상이 내 코스로** | 링크만 넣으면 동선을 자동 생성 | 유튜브 코스 결과 (지도+일정) |
| 7 | **진짜 다녀온 사람들의 후기** | 여행 인증 배지가 붙은 커뮤니티 | 커뮤니티 피드 (인증 배지 보이게) |
| 8 | **환급금 쓸 곳까지 안내** | 지역 온라인몰·가맹점 지도 | 온라인몰 탭 |

> feature graphic(1024×500)은 노출 빈도는 낮지만 **콘솔 필수 업로드 항목**이라 유지 — 1번 슬라이드와 같은 카피로 통일.

캡처 준비 팁: 심사위원 계정(sample) 데이터를 보기 좋게 세팅한 뒤 1080×1920로 캡처. 개인정보(실명·전화) 안 보이게.
