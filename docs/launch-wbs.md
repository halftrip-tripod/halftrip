## 0. 역할 (스탑 이후 체제)

| 사람 | 역할 |
| --- | --- |
| **규희** | **수정 메인 본체** — 넷이 QA하며 보낸 결함·엣지케이스를 취합해 전부 수정. 빌드(AAB) 만들어 하민에게 전달. 선행: **실서버 연결 빌드가 제대로 도는 것(로컬로그인)부터** |

| **하민** | **데이터·인프라·스토어 콘솔** — 키·계정·운영 데이터(심사 기간 10월~10/28 전후 접수 지역이 핵심) + **Play 콘솔 작업 전부**(계정 소유: 업로드·초대·설문 입력·프로덕션 신청·심사 대응) |
| **준서** | **문서 담당** — 공모전 제출 자료 제작·제출 + 일러스트(심사 기간 전후 지역 우선, 나머지는 디폴트 1종) |

### 결함 리포트 규칙 (→ 규희가 취합·수정)
발견하면 **①어느 상황(계정·데이터 상태) ②어느 화면 ③어떻게 발생(재현 단계) ④스크린샷**을 QA 시트에 기록.
서버 데이터 문제로 판명되면 하민, 문구·지역 정보는 준서 확인으로 라우팅.
